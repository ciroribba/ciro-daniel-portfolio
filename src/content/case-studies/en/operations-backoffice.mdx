## Reviewing and acting on transactions

I built dashboards with React and Ant Charts to review transactions by company and status. I worked on file uploads that requested status changes and displayed backend responses. I also contributed to the flow for sending messages to end users.

## Accessibility, architecture, and testing

I contributed to accessibility improvements and UI/UX guidelines that the team adopted. The architecture included a Backend for Frontend (BFF). Frontend flows had an 85–90% coverage target, with Vitest, React Testing Library, and Mock Service Worker in the test stack.
